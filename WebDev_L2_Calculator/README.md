## 📌 Project Overview

The **Modern Responsive Calculator** is a front-end web development project designed to provide a simple yet visually appealing calculator experience across desktop, tablet, and mobile devices.

The project demonstrates the practical use of:

- Semantic HTML structure
- Modern CSS styling
- Responsive web design
- JavaScript DOM manipulation
- Event handling
- Mathematical operations
- User-friendly interface design

The calculator provides users with an easy way to perform common arithmetic calculations directly in the browser.

---

## ✨ Features

### 🧮 Core Calculations

- Addition `+`
- Subtraction `−`
- Multiplication `×`
- Division `÷`
- Decimal calculations
- Continuous calculations
- Clear/reset functionality
- Delete/backspace functionality
- Result display

### 🎨 User Interface

- Modern calculator layout
- Clean and minimal design
- Clearly organized buttons
- Large calculation display
- Visually distinct operation buttons
- Interactive button states
- Smooth user interaction

### 📱 Responsive Design

The calculator is designed to work across different screen sizes:

- 📱 Mobile devices
- 📲 Tablets
- 💻 Laptops
- 🖥️ Desktop screens

The layout automatically adapts to smaller screens while keeping the calculator usable and visually balanced.
