## 📌 About The Project

The **Imran Khan Tribute Page** is a professionally designed, responsive website created to present the life journey, achievements, cricket career, philanthropic work, educational initiatives, and public-service journey of Imran Khan.

This project was developed as part of my **Web Development Internship at Oasis Infobytes**.

The project focuses on combining:

- Modern frontend development
- Responsive Web Design
- UI/UX principles
- Semantic HTML5
- CSS3
- Accessibility
- SEO fundamentals
- Factual research
- Professional documentation

The website presents information through a clean, structured and visually engaging interface designed for desktop, tablet and mobile users.

---

# 🎯 Project Objectives

The main objectives of this project were to:

- Build a professional tribute website using frontend technologies.
